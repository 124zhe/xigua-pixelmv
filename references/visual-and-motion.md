# 画面与动作基准

先看 `../assets/approved-demo/contact-sheet.jpg` 和 `poster.png`。这是用户接受的实际成片帧，不是未实现的概念图。

## 角色与场景

| 项目 | 延续的做法 | 避免回退到 |
|---|---|---|
| 人物 | 大头短身、简洁点眼、块状发型、短四肢；整个人物连贯 | 写实人体、细密发丝、复杂面部；大头拼细杆身体 |
| 造型一致性 | 同人衣服与剪影不随动作改变；新角度仍可识别 | 每个镜头重新随机生成不同身份 |
| 色彩 | 有限色阶，平涂大块面；轮廓和动作优先 | 光影纹理过密、满屏发光与细碎颗粒 |
| 背景 | 清楚的远中近层、少量城市细节；视觉复杂度低于主体 | 背景漂亮却吞掉角色，靠虚化补救信息层级 |
| 像素 | 明确边缘、相近像素尺度、最近邻显示 | 全景先压成 256×144 再放大/再裁近景导致糊 |
| 空间 | 地面、岸边、水面、座位、出货通道清楚 | 人物悬浮、穿过柜体、脚底滑动、绳端游离 |

本例男孩是海军蓝块状头发、蓝外套、奶白内衫；女孩是棕色短发、粉发夹、芥末黄开衫。继续《如果是我》时保留身份；其他歌曲不强制使用这对角色。

本例调色：夜空 `#161e3a`，轮廓 `#11172e`，河水 `#1c3555`，粉色 `#ee9eae`，奶油色 `#f7e5bc`，暖金 `#dfad67`，机关紫 `#635376`。采用深蓝夜色、粉色幻想、暖黄交流的关系；不要把它当所有歌曲的唯一配色。

## 道具可辨认，动作可理解

在最终构图、实际播放尺寸和镜头停留时长下判断观众能否认出物体，不能只看放大的素材原图。主要道具应有足够的轮廓、结构和明暗对比；不依赖歌词、说明文字或作者解释来猜它是什么。

- 信纸用纸边、折痕、笔迹、开合关系建立身份；相片要有相框边与可读内容；机械物件要露出决定其用途的结构。这里只是判断例子，不要求每首歌出现同一套道具。
- 建立物体从出现、被握住、操作到释放／收起的连续身份。远近景、正反面、姿态切换时，形状、比例、握点与数量应对应。
- 关键操作可用专门生成的“手＋道具”特写，或完整人物接触姿势。素材结构已经缺失时应重新生成；加速运动、放大空白块、粒子和镜头抖动不能补出结构。
- 接物先伸手，物体抵达握点后才承重抱稳；桌面滑送要交代推出、沿桌移动、到点接住，手递手则应接稳后再松手；放物先落到支撑面再松手。物体不能瞬移、穿脸、穿桌面或被前景意外吞掉。
- 给观众读懂准备、操作和结果的时间。换景时交代当前物体的去向，用匹配位置、形状或动作完成连接，避免不明大色块突然遮住人物。

简单形状仍可用于能一眼读懂的背景和机关；是否重生成由成片里的辨识度与接触质量决定，不用固定生成数量衡量质量。

## 三层有效运动

一镜通常选以下三层，按音乐需要留白，不规定每层必须一直运动。

1. **主事件**：划桨、拉绳、掏砝码、操作机器、抓起玩偶、接住物品。
2. **直接后果**：船前进/倒退，砝码撞击使船下沉，抓爪闭合后玩偶才升起，物品经通道返回。
3. **支持层**：水纹来自桨尖、硬币滚落、纸页翻动、灯光提示选择、歌词当前字回弹。

镜头运动用于发现关系或看清操作。缓慢缩放、雨、星光不能成为镜头唯一的“动画”。

## 动作时序与节奏

- 关键物件先给可辨认的完整状态，再操作、变形或进入特写。把身份、操作和结果分清，避免尚未看清就被遮满或切走。
- 在时间轴上安排准备、触发、响应、落定和结果停留。动作可以短促，结果应留到观众能读懂；持续时长服从歌曲和情绪，不机械套用固定帧数或同一种缓动。
- 连锁动作按因果错开起动，例如前牌倾倒后才带动后牌；落定后的轻微余势应符合物体性质。印章的进入缩放、纸页的折轴、绳索的张紧各有不同运动方式，不能统一套弹簧。
- 人物换姿与连续位移分开组织；身体动作、道具判定、数字和灯光围绕同一个事件配合。先确定主动作，再安排直接反馈和支持层，避免所有元素同时抢拍。
- 数量、选择和亮暗状态改变也可以推进事件，例如大量选项变灰、少量留下；不要只用移动距离或粒子数量衡量动态密度。

## 构图、镜头与冲击力

- 以大小、远近和明暗对比建立视觉重心，例如小人物面对巨大影子，关键道具进入前景。大特写要补足素材结构与像素，不放大含糊素材制造遮挡。
- 设计蓄力、爆发、余势和停顿的强弱关系。动作前的短暂等待或反向准备，为突然绷紧、撞击或揭示提供力度；不要让整段始终保持同样速度和强度。
- 镜头变化应带来新信息：操作特写交代触点，拉远揭示力量来源；也可用主观、俯视、低角度、前景遮挡或纵深运动改变观看关系。转场保留可追踪的物体或空间联系，交代它们如何进入下一镜。
- 在副歌或情绪转折处设计有记忆点的关键画面，用前后较安静的镜头衬托。重复段落改变尺度、人数、观看角度或事件结果；强弱服从当前歌曲，不把欢快群舞或固定高潮数量套到所有 MV。
- 爆发时刻让主体剪影和颜色对比明确，背景适当收敛；给手、脸、道具和歌词分别留空间。闪光、抖动和粒子可加强已经成立的事件，不能掩盖素材、接触或杂线问题。

《如果是我》的可选设计：船靠近 → 绳结特写绷紧 → 船身顿住、人物因惯性前倾、水纹扩散 → 拉远揭示自己的影子。它把动作力度和原因揭示放在同一事件中，是设计示例，不代表成片已经实现；其他歌曲另选符合情绪的事件。

## 人物动作

- 使用针对动作设计的整姿帧。准备、触物、用力、收势至少应能被读出；不要求每一个输出帧都生成新人物。
- 划船例用四个姿态在约 0.96 秒内完成一次循环。输出 24 fps，姿态分段保持，位置与水纹连续变化。这个节奏是本例参数，应随新歌节拍和动作改。
- 拉绳动作先双脚撑地、身体后仰，船后退；人物没有施力时船不能凭空反向滑走。
- 静止阅读可以用读书、翻页、抬眼几个明确姿态。不用全身匀速上下漂浮来表示“活着”。
- 身体朝向或动作大变时换专门姿势。不可把站姿硬旋转成躺姿、把身体拉扁成坐姿。

## 接触锚点与遮挡

| 关系 | 应锁定的点 | 必查时刻 |
|---|---|---|
| 脚与地面 | 足底/支撑脚，地面高度 | 换姿、起落、移步、近景切换 |
| 手与道具 | 握柄/按钮/物件接触点 | 接触前、施力中、松手后 |
| 船与水 | 船底或水线，不以整张图中心定位 | 换划桨帧、受拉、载重下沉 |
| 绳与船 | 船尾固定端、手的握绳端 | 船移动、镜头拉远、绳松紧改变 |
| 人物与座位 | 臀部支撑和脚的位置 | 坐下、抬起、转头 |
| 玩偶与抓爪 | 夹持点与玩偶顶部 | 闭合、升起、平移、松开 |

姿势帧的包围盒不同，不能逐帧都按画布中心对齐。用脚底/船底等基准点计算落位；抓爪、绳、手的位置共享世界坐标。水面可以遮住浸水桨尖，不能盖掉握桨的手。退回物品给可见的出口或路径，避免直接穿过玻璃到掌心。

## 字幕

- 底部是一句完整、稳定可读的歌词；当前字按歌声起点轻跳，唱过与未唱过的字可以有色差。
- 本例逻辑字高 32 px、跳高约 10 px、回弹约 0.32 s；1920×1080 输出相当于约 64 px 字高、20 px 位移。以实际歌词长度和安全区调整。
- 深紫底板、奶白字、粉色描边形成像素 MV 气质；不必所有项目都保留同款字幕底板。
- 场景中只取少量动态副本：如“靠近”两字靠拢、“退后”退回、玩偶胸前的“我”。字幕原文不应被拆走而难以跟唱。
- 主操作占底部时调整构图或字幕位置，不用字压住手、船沿、按钮、玩偶出货口。

## 杂线与绘制残留

画面里的线条应有可读的归属：轮廓、场景结构、绳索、动作轨迹或明确的叙事连接。不能解释它属于什么、连接哪里、何时应该出现的孤立线条，先标为缺陷，查明来源后清除或重新设计；不能仅以“像素风格”解释异常。

- 特别查横穿人物／道具的直线、悬空线段、图集邻格碎片、透明裁切残边、调试辅助线、旧镜头路径以及转场结束后仍留下的边框。
- 区分有意义的绳索、栏杆、地砖边缘与无意义残留，避免一刀切删除正常结构。合法线条也要检查端点、遮挡和出现时机；用途不清就修构图或连接关系。
- 从整幅画面扫到局部：四边、背景暗区、人物周围和物体刚移开的区域都要看；不能只盯主角与字幕。正常速度看是否闪现或拖尾，局部放大看细线和锯齿残边。
- 修复应针对源绘制、裁切或状态清理。不要用模糊、暗化、覆盖装饰等办法掩盖杂线。

## 镜头清晰度

本例逻辑场景 960×540，输出 1920×1080 最近邻缩放，人物图集原尺寸分别 1774×887、1448×1086。高分辨率文件与清楚的实际轮廓是两回事：新场景必须看输出 100% 尺寸的实际帧。大特写需要更充足的角色源图像素，不能在很小的全景上继续裁切放大。
