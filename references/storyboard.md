# 分镜设计：让隐喻能被操作

## 核心方法

先明确这一句在表达什么心理或关系变化，再选择一个熟悉的规则，最后设计人物怎样行动、规则如何回应。不要停在“歌词里有某个名词，所以画这个名词”。

| 抽象内容 | 熟悉的规则 | 可拍的事件 |
|---|---|---|
| 想靠近，却自己退缩 | 划船、绳索受力 | 送桨入水→船前进→被拉停→拉远发现拉绳的是自己的影子 |
| 觉得自己顾虑太多 | 船的载重 | 从自己口袋取出问号砝码→落进船→水位抬高→自己停止加重 |
| 想成为对方选择的人 | 抓取机与空座位 | 自己的玩偶被叫中→抓起→将到座位→自己的影子启动退回 |

参考片曾将数拍转成跳舞机、将“加入失恋共和国”转成护照入境。这两个例子说明转译方法，不意味着以后每首歌都放跳舞机或护照。

## 先看参考，标明看到了多少

用户给了新视频参考时，实际检查多个段落与关键动作的前后状态：人物姿势、道具状态、镜头、字幕、转场、重复副歌差异。只有截图就只分析截图；分段抽帧不要描述为连续完整观看，也不要猜测作者所用模型、软件或动作帧数量。

对比要落到我们自己的实际视频：选对应动作帧，检查是否只是背景替换、整人滑动、机械摆肢、悬浮足底。不能只总结“氛围好、动态多”。

此前参考来源：[许愿池已打烊《讨厌红楼梦 mv 重制版像素版本》](https://www.douyin.com/video/7695699433842199730)。2026-10-23 复看覆盖多个段落，并对护照约 36.4–40.3 秒、舞蹈约 81.7–85.5 秒、倒牌约 116.0–120.9 秒连续采样；这不是全片逐帧审查，也未测定原片帧率、音乐节拍或制作软件。新任务若要依赖细节，应重新核对。不要复制其角色、分镜组合或素材。

可复用的观察：护照先展示封面再翻开，印章放大进入后缩小落定；规则牌依次倾倒后保持结果；舞蹈换姿与箭头、计数配合；选角由大量亮起变为少量保留；后段通过天空、群舞和背面视角改变空间。提炼这些状态变化、错时响应和构图方法，不强制复用相同道具或场景。

## 逐句分镜表

用以下字段记录，而不是仅给一段图像提示词：

| 字段 | 要写清的内容 |
|---|---|
| 歌词与时码 | 已确认原词；句起止；必要的字头/重拍 |
| 情绪/矛盾 | 想做什么，是什么阻力，认识怎样变化 |
| 场景规则 | 观众能马上理解的装置、行为或物理规则 |
| 起始状态 | 谁在什么地方，手里有什么，谁知道原因 |
| 动作 | 准备、接触、施力、松手等可见步骤 |
| 直接后果 | 物体与人物处境发生什么改变 |
| 节奏与停留 | 准备、动作触发、反馈落定、结果留白；多对象如何依次响应 |
| 视觉重心与冲击 | 第一眼看哪里；关键处的尺度、动静或明暗反差；前后镜头怎样衬托 |
| 景别/揭示 | 何时给操作近景，何时拉开揭示关系 |
| 字幕 | 稳定阅读层；参与场景的少量关键词 |
| 转场 | 当前动作或道具如何带出下一镜 |
| 所需素材与锚点 | 哪些完整姿势、表情、道具状态、接触基准 |

时码来源不可靠时先标暂定，再校准，不伪造精确逐字时间。长句拆成操作与反应两个镜头通常比全程正面站立更有效。

## 组织整曲

- 保留心理主线；用少量母题贯穿多个段落。连续两到四句可以发展同一机关，不必每句换一个新场景。
- 幻想要有现实入口与出口，例如纸张展开成剧场，硬币遮满镜头再进入游戏机。画面大胆，因果保持清楚。
- 主歌、副歌、桥段可以改变尺度、空间、配色或镜头语法；人物身份保持一致。
- 第二次副歌再次使用母题时，改变动作、操作者或结局，让重复成为发展。
- 结尾回收开头的未完成动作。音乐与情绪需要安静时，减弱背景和字幕动作。
- 《如果是我》的女孩从未明确拒绝或答应；男孩一直替她作答。延续该项目不得把幻想立牌当成女孩真实回应。其他歌曲按自己的歌词建立人物动机。

## 把方案变成可执行 demo

选择一小段有完整变化的连续音乐：一个事件、一次原因揭示、至少一个道具反馈或转场。输出像本例 30.6 秒这样的真正动画，验证整体语言后再扩展。

分镜目标不是堆满创意名词。若一句说明删掉“镜头推近、粒子飘动、字幕跳动”后已没有动作，说明还没设计完。
